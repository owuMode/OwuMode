ChainVerifier Documentation

ChainVerifier is a Windows tool for finding, verifying, and managing pointer chains in any running process. It's designed to be fast, clean, and reliable — whether you're a beginner following a pointer chain tutorial or a reverse engineer working on a complex target.

💡 New to pointer chains? A pointer chain is a sequence of memory addresses where each address contains a pointer to the next one, ending at the actual value you want. ChainVerifier lets you define these chains and resolve them live.

Installation

  1. Download the latest ZIP from the download page
  2. Extract the folder anywhere — no installer needed
  3. Right-click ChainVerifier.exe → Run as Administrator
⚠ Do not move the EXE out of its folder — it needs the _internal\ directory alongside it to run.

Attach to Process

Before doing anything, you need to attach to a target process.

  1. Click Tools → Attach to Process... or click the Browse... button in the top bar
  2. Search for your target by name or PID
  3. Double-click the process (or select + click Attach)

Once attached, the process name and base address appear in the top bar. If the target process closes, ChainVerifier auto-detaches.

Managing Chains

Chains live in the Chains Editor at the bottom of the main window.

  • Add — enter base offset, offsets list, and value type
  • Edit — double-click a chain or select + click Edit
  • Delete — remove a single chain
  • Clear All — remove every chain

Chain fields

  • Name — auto-generated or custom
  • Base Offset — hex offset from module base (e.g. 0x89D244)
  • Offsets — comma-separated hex offsets, e.g. 0x140, 0x20, 0x3C
  • Value Type — int32, int64, float, double, or pointer

Verify Chains

The primary feature — resolve all your chains against a target address.

  1. Enter the Target address in the top bar (e.g. 0x7A5950)
  2. Click Verify All Chains
  3. Results table shows: Final Address, Match (YES/NO), Value, Status

Matching chains highlight in green. Double-click any value in the results to edit it live in memory. Double-click a Description cell to add notes.

💡 Use Edit → Delete All Error Chains after verifying to quickly remove chains that failed to resolve.

🕵️ Scan Modes

AOB Pattern Scan

Search memory for byte patterns with wildcards. Supports ?? for unknown bytes.

48 8B ?? 05 ?? ?? ?? ??

Range Scan

Find all values within a numeric range. Useful for health, ammo, coordinates.

Unknown Value Scan

First scan snapshots memory. Next scan filters with changed/unchanged/increased/decreased. Great for finding values without knowing them.

String Scan

Search for ASCII or UTF-16 strings in memory. Case-sensitive toggle available.

Pointer Scan

Find multi-level pointer chains that point to a target address. Configure max level (1–7) and max offset.

🛠️ Tools

Freeze Values

Lock values in place with a background writer thread. Add addresses + values, and ChainVerifier writes them continuously so the game/target can't change them.

Hex Viewer / Editor

Inspect and edit raw bytes at any address. Write bytes in hex format.

48 8B 05 90

Import Cheat Engine Pointer Map

Load .sqlite files exported from Cheat Engine. ChainVerifier auto-detects format and imports all pointer chains in one go.

Export Results

Save verification results as CSV, JSON, or TXT via File → Export Results...

Save & Load

Chain files use the .owu extension — encrypted with XOR + SHA-256 checksum + zlib compression.

  • File → New — start fresh
  • File → Open — load a .owu file
  • File → Save / Save As — save your chains and current results
  • Recent Files — quick access to recently used files

⚙ Settings

Access settings via the Settings menu. Sections include:

  • General — startup behavior, language, updates
  • Appearance — fonts, colors, themes, layout
  • Behavior — live update interval, confirmations
  • Performance — threads, buffer size, scan mode
  • Hotkeys — global keyboard shortcuts
  • File & Logs — auto-save, log rotation
  • Advanced — cache size, undo history, debug

⌨ Keyboard Shortcuts

  • Ctrl+N — New file
  • Ctrl+O — Open file
  • Ctrl+S — Save
  • Ctrl+Shift+S — Save As
  • Ctrl+Z — Undo
  • Ctrl+Y — Redo
  • Ctrl+U — Check for updates
