10 Antivirus & False Positives

Memory scanning tools are frequently flagged by antivirus software as PUP (Potentially Unwanted Program), hacktool, or riskware. This is a known false positive caused by the tool's nature, not by any malicious code.

Why this happens:

  • ChainVerifier reads and writes other processes' memory
  • Antivirus heuristics flag any program that does this
  • Legitimate tools like Cheat Engine, Process Hacker, and x64dbg face the same issue

What we do:

  • Source code is publicly available on GitHub for inspection
  • No obfuscation, no hidden behavior, no network calls except update checks
  • We encourage submitting the binary to VirusTotal for verification
If your antivirus flags ChainVerifier, you can add an exclusion for the folder. If you're not comfortable doing that, don't use the tool — that's a valid choice.
