How to Install

Get up and running in 4 steps

1

Download the ZIP

Click any Download button above to fetch the latest version.

2

Extract the EXE

Right-click the ZIP → Extract All. You only need the single ChainVerifier.exe inside — no other files required.

3

Run as Administrator

Right-click ChainVerifier.exe → Run as Administrator. Required for memory access.

4

Attach & Verify

Use Tools → Attach to Process to pick your target, then click Verify All Chains.
